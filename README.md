# Product work is changing

A small, single-page site about how product work changes when AI can build a first version in an afternoon.

It tells one fictional story about a scaleup in four clickable chapters, with a working prototype. Then it tells the same story twice, side by side, without AI and with AI. The site also includes an explainer of the terms it uses and a decision log of the real product decisions behind it.

The company, people and figures are fictional.

## Run it

Open `index.html` in a browser. There is no build step and there are no dependencies, apart from Google Fonts.
